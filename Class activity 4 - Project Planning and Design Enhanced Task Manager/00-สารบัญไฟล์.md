## โค้ด Python (แบ่งตามชั้นสถาปัตยกรรม)

| ไฟล์ | ชั้น | หน้าที่ |

## เมนูในโปรแกรม

| เมนู | ความสามารถ | สถานะ |
| --- | --- | --- |
| 1–3 | เพิ่มงาน 3 ชนิด (ทั่วไป / ครบกำหนด / ความสำคัญ) | ใช้งานได้ |
| 4 | แสดงรายการงานทั้งหมด | ใช้งานได้ |
| 5–6 | เปลี่ยนสถานะ / ลบงาน | ใช้งานได้ |
| 7–9 | ค้นหา / กรอง / เรียงลำดับ | **Placeholder** (เป็นภารกิจขั้นถัดไป) |
| 0 | ออกจากโปรแกรม | ใช้งานได้ |

> เมนู 7–9 ยังไม่ทำงานจริง **โดยเจตนา** — สัปดาห์นี้เน้นการวางแผนและออกแบบ
> การพัฒนาจริงเป็นภารกิจที่ 2–4 ใน `README.md` (ดูหัวข้อ 4.1 และ 8.5 ของรายงาน)

## งานที่ยังเหลือในขั้นถัดไป

เขียน `search_tasks()`, `filter_tasks()`, `sort_tasks()` ใน `src/task_manager.py`
ตามแนวทางที่เขียนไว้ใน docstring ของแต่ละเมธอด — **ไม่ต้องแก้ `cli_interface.py` เลย**
เพราะส่วนรับอินพุตและแสดงผลเขียนรอไว้ครบแล้ว
