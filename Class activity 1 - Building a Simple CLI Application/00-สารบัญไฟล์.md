## วิธีรัน

```bash
cd "Class activity 1 - Building a Simple CLI Application"
python main.py
```

ไม่ต้องติดตั้งไลบรารีเพิ่ม ใช้เฉพาะ `json`, `os`, `sys` ซึ่งมากับ Python อยู่แล้ว

## ผลการทดสอบการจัดการข้อผิดพลาด

| ป้อน | ผลลัพธ์ |
| --- | --- |
| `9` (เมนู) | `[Error] Invalid choice. Please select an option between 1 and 8.` |
| `abc` (ID) | `[Error] Invalid input: invalid literal for int() ... Please enter a positive number` |
| `99` (ID) | `[Error] Task with ID #99 was not found.` |
| ค่าว่าง (description) | `[Error] Description cannot be empty.` |
| `SuperHigh` (priority) | `[Warning] Invalid priority 'SuperHigh'. Defaulting to 'Medium'.` |

ทุกกรณีโปรแกรมไม่ crash — แสดงข้อความแล้ววนกลับเมนูหลัก
