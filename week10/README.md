# Week 10 — LabX BASIC: Automating Spreadsheets (Excel & Google Sheets)

โปรเจกต์นี้สาธิตการควบคุมไฟล์ Excel (`.xlsx`) ด้วย Python ผ่านไลบรารี **openpyxl**
โดยอ่านข้อมูลการขายจากไฟล์ต้นทาง คำนวณยอดรวม แล้วสร้างรายงานเป็นไฟล์ Excel ใหม่พร้อมจัดรูปแบบให้อ่านง่าย

## แนวคิดสำคัญที่สาธิตในโปรเจกต์

* **openpyxl** — อ่าน เขียน และแก้ไขไฟล์ `.xlsx`
* **Workbook & Worksheet** — โหลด สร้าง และบันทึกเวิร์กบุ๊ก รวมถึงการเข้าถึงและสร้างชีตใหม่
* **Cell Manipulation** — อ่าน/เขียนค่าเซลล์ทั้งแบบระบุพิกัด (`A1`) และแบบระบุแถว-คอลัมน์ (`cell(row, column)`)
* **การประมวลผลข้อมูล** — วนอ่านทีละแถวด้วย `iter_rows()` คำนวณราคารวมต่อรายการและยอดรวมทั้งหมด
* **การจัดรูปแบบ** — กำหนดฟอนต์ สีพื้น เส้นขอบ การจัดวาง และรูปแบบตัวเลขสกุลเงิน
* **การปรับความกว้างคอลัมน์** — คำนวณความกว้างจากความยาวข้อความที่ยาวที่สุดในคอลัมน์

## โครงสร้างโปรเจกต์

```text

├── .gitignore
└── README.md
```

## การติดตั้งและวิธีรัน

```bash
pip install openpyxl
python main.py
```

> **สำคัญ:** ต้องรันจากในโฟลเดอร์ `week10` เพราะ `main.py` อ้างเส้นทางไฟล์แบบสัมพัทธ์ (`data/input_sales.xlsx`)
> ซึ่งอิงกับตำแหน่งที่รันคำสั่ง ไม่ใช่ตำแหน่งของตัวไฟล์สคริปต์

โปรแกรมจะทำงานตามลำดับนี้:

1. โหลด `data/input_sales.xlsx`
2. วนอ่านข้อมูลทีละแถว โดยข้ามแถวว่างอัตโนมัติ
3. คำนวณ `Total Price` ของแต่ละรายการ (Quantity × Unit Price) และยอดรวมทั้งหมด
4. สร้างเวิร์กบุ๊กใหม่พร้อมชีตชื่อ `Sales Report`
5. เขียนข้อมูลพร้อมจัดรูปแบบ (หัวตารางเขียว แถวยอดรวมเหลือง เส้นขอบ รูปแบบสกุลเงิน)
6. บันทึกเป็น `data/output_sales_report.xlsx`

## ข้อมูลตั้งต้น (`data/input_sales.xlsx`)

| Product Name | Quantity | Unit Price |
| :----------- | :------- | :--------- |
| Laptop | 2 | 1200.50 |
| Mouse | 5 | 25.00 |
| Keyboard | 3 | 75.99 |
| *(แถวว่าง)* | | |
| Monitor | 1 | 300.00 |
| Printer | 1 | 150.00 |

แถวว่างถูกใส่ไว้ตามที่โจทย์กำหนด เพื่อพิสูจน์ว่าสคริปต์ข้ามแถวว่างได้จริงด้วยเงื่อนไข `if not any(row)`

## จุดบกพร่องที่พบและการแก้ไข

โค้ดต้นฉบับรันผ่านและคำนวณถูกต้องทุกค่า แต่พบข้อบกพร่องด้านการจัดรูปแบบ 2 จุด
รายละเอียดพร้อมภาพเปรียบเทียบอยู่ในรายงาน PDF หัวข้อที่ 5

| # | อาการ | การแก้ไข |
| --- | --- | --- |
| 1 | คอลัมน์ `Unit Price` เป็นจำนวนเงินเหมือน `Total Price` แต่ไม่ได้จัดรูปแบบ จึงแสดงเป็น `1200.5`, `25`, `300` | กำหนด `number_format = currency_format` ให้เซลล์ Unit Price |
| 2 | เซลล์ป้าย `Grand Total:` ไม่มีเส้นขอบ ขณะที่เซลล์อื่นทั้งตารางมีครบ | เพิ่ม `grand_total_label_cell.border = thin_border` |

## การแก้ปัญหาที่พบบ่อย

* **`FileNotFoundError`** — ตรวจว่ามี `data/input_sales.xlsx` จริง และรันคำสั่งจากในโฟลเดอร์โปรเจกต์
* **`InvalidFileException`** — ไฟล์อาจเป็นสกุล `.xls` แบบเก่าซึ่ง openpyxl ไม่รองรับ ต้องบันทึกเป็น `.xlsx`
* **`TypeError` / `ValueError`** — เกิดเมื่อคอลัมน์ตัวเลขมีข้อความปน โค้ดดักไว้ด้วย `try-except` แล้วข้ามแถวนั้นพร้อมแจ้งเตือน
* **จัดรูปแบบแล้วไม่ขึ้น** — ต้องกำหนดสไตล์ให้เซลล์ **ก่อน** บันทึกไฟล์เสมอ
* **เซลล์ที่ merge** — กำหนดเส้นขอบที่เซลล์ซ้ายบนก็พอ openpyxl จะกระจายเส้นขอบรอบนอกให้ทั้งช่วงเอง

## แนวทางต่อยอด

* เชื่อมต่อ Google Sheets ผ่าน `gspread` และ Google Sheets API (ต้องตั้งค่า OAuth 2.0)
* เพิ่มการตรวจสอบความถูกต้องของข้อมูลนำเข้า (ค่าติดลบ ค่าว่าง ชนิดข้อมูลผิด)
* สร้างกราฟในไฟล์ Excel ด้วยความสามารถ chart ของ openpyxl
* ใช้ conditional formatting ไฮไลต์รายการที่ยอดขายสูง/ต่ำผิดปกติ
* อ่านข้อมูลจากฐานข้อมูลแล้วส่งออกเป็น Excel อัตโนมัติ
