## 1. `Lab/` — Lab ประจำสัปดาห์

Lab ที่ทำในคาบเรียนประจำแต่ละสัปดาห์ ตั้งชื่อโฟลเดอร์ตามสัปดาห์เพื่อให้เรียงลำดับได้ถูกต้อง

| โฟลเดอร์ | หัวข้อ |
|---|---|
| `Week 01 - Environment Setup & Variables` | ติดตั้งเครื่องมือ ตัวแปร และชนิดข้อมูลพื้นฐาน |
| `Week 02 - Conditionals & Control Flow` | `if` / `elif` / `else` และการรับค่าจากผู้ใช้ |
| `Week 03 - Control Flow Loops` | `for` / `while` loops |
| `Week 04 - Lists & Tuples` | List และ Tuple |
| `Week 05 - Dictionaries & Sets` | Dictionary และ Set |
| `Week 06 - Functions & Modules` | ฟังก์ชัน และการสร้าง/เรียกใช้ module |
| `Week 07 - Building a Simple CLI Application` | สร้างโปรแกรม CLI Task Manager |
| `Week 08 - OOP Fundamentals & Refactoring` | OOP และ refactor CLI Task Manager |
| `Week 10 - Interacting with Web APIs` | เรียกใช้งาน Web API ด้วย `requests` |
| `Week 11 - Project Planning & Design` | วางแผนและออกแบบ Enhanced Task Manager |

> **หมายเหตุ** — สัปดาห์ที่ 9 เป็นสัปดาห์สอบกลางภาค จึงไม่มีโฟลเดอร์ `Week 09`
> และ Lab ของ Week 07, 08, 10, 11 คือไฟล์งานที่เดิมชื่อ `Class activity 1–4`

## สรุปความต่างจากโครงสร้างที่กำหนด

โครงสร้างในที่นี้ทำตามที่กำหนดครบทั้ง 6 โฟลเดอร์ โดยมีรายละเอียดเพิ่มเติมดังนี้

| หัวข้อ | รายละเอียด |
|---|---|
| ชื่อโฟลเดอร์ย่อยใน `Lab/` | ใช้รูปแบบ `Week NN - <หัวข้อ>` เพื่อไม่ให้เลขสัปดาห์ปนกับเลข LabX และเรียงลำดับได้ถูกต้อง |
| ไม่มี `Week 09` ใน `Lab/` | สัปดาห์ที่ 9 เป็นสัปดาห์สอบกลางภาค ไม่มีงาน |
| `mini Project/` และ `Final Project/` | ไม่ได้โคลนโปรเจกต์เข้ามา ใช้ไฟล์ `.md` ที่มีลิงก์ไปยังโปรเจกต์ตามทางเลือกที่อนุญาต เพราะทั้งสองเป็นงานกลุ่มที่อยู่ใน repository ของกลุ่ม |
| `certificate/` | มีทั้งไฟล์ `.png` (ภาพ) และ `.pdf` (ต้นฉบับที่ดาวน์โหลดจาก netacad) |
| ไฟล์ซ้ำที่ลบออก | สำเนาของ `Class activity 2` ที่ซ้อนอยู่ในโฟลเดอร์ `Class activity 1` (เนื้อหาเหมือนกันทุกไฟล์) และโฟลเดอร์ `week11` ตัวเก่า ซึ่งไฟล์ทั้งหมดมีอยู่แล้วใน `Lab X Basic/Lab 4 Basic` ที่ครบกว่า |
