## ผลการรันจริง (ทดสอบกับ jsonplaceholder.typicode.com)

| เมนู | Endpoint | ผลที่ได้ |
| --- | --- | --- |
| 1 | `GET /todos/1` | dict 1 รายการ — "delectus aut autem", Pending |
| 2 | `GET /posts` | list 100 รายการ (แสดง 5 แรก) |
| 3 | `GET /todos?userId=1` | list 20 รายการ — เสร็จ 11 / รอ 9 |

## การจัดการข้อผิดพลาดที่ทดสอบแล้ว

| ป้อน | ผลลัพธ์ |
| --- | --- |
| `9` (เมนู) | ตัวเลือกไม่ถูกต้อง กรุณาป้อนตัวเลขระหว่าง 1 ถึง 4 |
| `xyz` (ID) | 'xyz' ไม่ใช่ตัวเลขที่ถูกต้อง |
| `-5` (ID) | รหัส TODO ID ต้องเป็นจำนวนเต็มบวก |
| `9999` (TODO ID) | `[ERROR] HTTP Error (404)` → ไม่พบข้อมูล |
| `99` (User ID) | ไม่พบรายการงาน TODO (API คืน 200 + ลิสต์เปล่า) |

> **จุดที่น่าสนใจ:** `/todos/9999` ได้ **404** แต่ `/todos?userId=99` ได้ **200 + ลิสต์เปล่า**
> โค้ดแยกสองกรณีนี้ถูกต้องด้วย `if user_todos is not None:` (ดูหัวข้อ 9 ในรายงาน)
