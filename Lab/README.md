# Lab — Lab ประจำสัปดาห์

Lab ที่ทำประจำแต่ละสัปดาห์ของรายวิชา CP352301 Script Programming · Section 2

ชื่อโฟลเดอร์ใช้รูปแบบ `Week NN - <หัวข้อ>` เพื่อให้เรียงตามลำดับสัปดาห์ได้ถูกต้อง
และไม่ให้เลขสัปดาห์สับสนกับเลขของ LabX ใน `Lab X Basic/` และ `Lab X Advance/`

| สัปดาห์ | โฟลเดอร์ | หัวข้อ | ไฟล์สำคัญ |
|---|---|---|---|
| 1 | `Week 01 - Environment Setup & Variables` | ติดตั้งเครื่องมือ ตัวแปร และชนิดข้อมูลพื้นฐาน | `sec2_week1_663380347-5.py` + สรุปเนื้อหา (PDF) |
| 2 | `Week 02 - Conditionals & Control Flow` | `if` / `elif` / `else` และการรับค่าจากผู้ใช้ | `week2_Lab2-1.py`, `week2_Lab2-2.py` + รายงาน (PDF) |
| 3 | `Week 03 - Control Flow Loops` | `for` / `while` loops | `Week 3_ Control Flow_ Loops.docx` |
| 4 | `Week 04 - Lists & Tuples` | List และ Tuple | `Lab_4_Script_.ipynb` + รายงาน (DOCX) |
| 5 | `Week 05 - Dictionaries & Sets` | Dictionary และ Set | `Lab_5_Data_Structures_Dictionaries_&_Sets.ipynb` + รายงาน (PDF) |
| 6 | `Week 06 - Functions & Modules` | ฟังก์ชัน และการสร้าง/เรียกใช้ module | `week6_labs.py` + รายงาน (PDF) + ภาพผลการรัน |
| 7 | `Week 07 - Building a Simple CLI Application` | สร้างโปรแกรม CLI Task Manager | `main.py`, `src/`, `screenshots/` + โจทย์และรายงาน |
| 8 | `Week 08 - OOP Fundamentals & Refactoring` | OOP และ refactor CLI Task Manager | `starter_code/`, `solution/`, `colab/`, `screenshots/` + โจทย์และรายงาน |
| 10 | `Week 10 - Interacting with Web APIs` | เรียกใช้งาน Web API ด้วย `requests` | `main.py`, `src/api_client.py`, `assignments/`, `colab/` + โจทย์และรายงาน |
| 11 | `Week 11 - Project Planning & Design` | วางแผนและออกแบบ Enhanced Task Manager | `PLAN.md`, `main.py`, `src/`, `screenshots/` + โจทย์และรายงาน |

## หมายเหตุ

* **ไม่มี `Week 09`** — สัปดาห์ที่ 9 เป็นสัปดาห์สอบกลางภาค ไม่มีงานส่ง
* **Week 12 ขึ้นไป** — งานของสัปดาห์ที่ 12 เป็น LabX อยู่ใน [`../Lab X Basic/Lab 5 Basic`](../Lab%20X%20Basic/Lab%205%20Basic)
  และ [`../Lab X Advance/Lab 5 Advance`](../Lab%20X%20Advance/Lab%205%20Advance)
  ส่วนสัปดาห์ที่ 12–15 เป็นช่วงทำ Final Project ดู [`../Final Project`](../Final%20Project)
* Lab ของ Week 07, 08, 10 และ 11 คือไฟล์งานที่เดิมตั้งชื่อว่า `Class activity 1` – `Class activity 4`
  (ดูได้จากชื่อไฟล์โจทย์ภายในโฟลเดอร์ เช่น `โจทย์แลป - Week 7 Building a Simple CLI Application.docx`)
