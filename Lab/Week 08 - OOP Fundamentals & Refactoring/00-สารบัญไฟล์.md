## วิธีรัน

```bash
cd solution
python main.py                              # รันโปรแกรม
python -m unittest discover -s tests -v     # รันชุดทดสอบ
```

ใช้เฉพาะไลบรารีมาตรฐานของ Python ไม่ต้องติดตั้งอะไรเพิ่ม

## ผลการทดสอบ

**Unit test:** `Ran 11 tests ... OK` (ผ่านทั้งหมด)

**การจัดการข้อผิดพลาด:**

| ป้อน | ผลลัพธ์ |
| --- | --- |
| `9` (เมนู) | `Invalid choice. Please enter a number between 1 and 5.` |
| `abc` (ID) | `Invalid input. Please enter a number for Task ID.` |
| `99` (ID) | `Error: Task with ID 99 not found.` |
| ค่าว่าง | `Task description cannot be empty.` |
| ทำงานที่เสร็จแล้วซ้ำ | `Task ID 2 is already completed.` |
