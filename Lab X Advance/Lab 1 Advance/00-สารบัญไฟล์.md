## โค้ด Python

| ไฟล์ | หน้าที่ |
| --- | --- |
| `main.py` | จุดเริ่มต้น: โหลด config → รัน agent → บันทึกผล |
| `src/scraper_agent.py` | สมองของ agent — อ่าน config นำทาง ดึงข้อมูล เปลี่ยนหน้า |
| `src/config_parser.py` | โหลดและตรวจสอบความถูกต้องของไฟล์ config |
| `src/data_models.py` | dataclass `Product` สำหรับเก็บข้อมูลที่ดึงมา |
| `src/driver_manager.py` | จัดการ Selenium WebDriver (Chrome / Firefox) |
| `src/utils.py` | `save_data_to_json()`, `wait_for_element()`, `safe_click()` |
| `test_setup.py` | ทดสอบว่าติดตั้ง Selenium + WebDriver สำเร็จ |
| `requirements.txt` | `selenium`, `webdriver-manager` |

## วิธีรัน

```bash
cd "LabX ADV1 - Advanced Web Scraping and Automated Agents"
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python test_setup.py      # ทดสอบว่า Selenium ใช้งานได้
python main.py            # รัน agent
```

> **ข้อควรระวัง:** ต้องรัน `python main.py` จากภายในโฟลเดอร์นี้เท่านั้น
> เพราะ `main.py` อ้างอิงพาธแบบสัมพัทธ์ (`configs/...`, `data/...`)

## สิ่งที่ยังควรปรับปรุง (ดูรายละเอียดในหัวข้อ 9 ของรายงาน)

1. ยังไม่มีไฟล์ `docs/ETHICS.md` ตามที่โจทย์กำหนด
2. `.gitignore` ว่างเปล่า ทำให้ `src/__pycache__/` ถูกอัปขึ้น Git
3. `_parse_item()` ใช้ `except:` เปล่า ๆ ควรระบุ `NoSuchElementException`
4. `config_parser` ยังไม่ตรวจสอบคีย์ `pagination_selector`
5. ชื่อหนังสือ 22 จาก 40 รายการถูกตัดสั้น — ควรอ่านจากแอตทริบิวต์ `title`
